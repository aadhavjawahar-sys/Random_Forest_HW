# Random Forest Introductory Project

A following ML model employs a random forest, building upon the prior [**decision tree**](https://github.com/aadhavjawahar-sys/DecisionTree-HW) project.

> According to [IBM](https://www.ibm.com/think/topics/random-forest), "Random forest is a commonly-used machine learning algorithm, trademarked by Leo Breiman and Adele Cutler, that combines the output of multiple decision trees to reach a single result. Its ease of use and flexibility have fueled its adoption, as it handles both classification and regression problems."

***

## Data used

The data used for this ML model is a default dataset about **breast cancer*, where the target variable is the malignant tumor (0 : benign, 1 : malignant) and the features are likely data about the dimensions, size, or shape of the tumor itself.

## Comparison

After comparing both the *Decision Tree Model* and *Random Forest model* for the same dataset at the depth of 8, I observed that the random forest performed better, which an accuracy of 0.95 in comparison to the 0.91 accuracy of the decision tree model.
